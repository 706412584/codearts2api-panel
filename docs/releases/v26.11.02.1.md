修复模型 ID 大小写导致的「模型未注册」错误。

### 修复

- 盘古系列模型恢复可用：此前种子表把展示名 `OpenPangu-2.0-Pro` / `OpenPangu-2.0-Flash` 当作上游注册名，而 InferHub 注册的是全小写 `openpangu-2.0-pro` / `openpangu-2.0-flash`，请求一律被回 `InferHub.002002009.404`（The model is not registered）。目录发现也纠不回来：已知索引只在发现到混合大小写时才覆盖种子，而注册名是全小写。现在种子只做目录发现之前的兜底，发现结果优先，两条注册名同时改正；`GLM-5.2-ArkTS-SPARK` 因是展示名（真正的 ID 为 `glm-5.2-sft-harmony`）从种子里移除。
- 网关发出的模型 ID 改为「被选中账号自己目录里登记的写法」。目录守卫按大小写不敏感判断，上游却按注册名精确匹配，两套口径不一致时请求照旧放行，白耗一次上游调用后仍以 404 结束。可用性探测同步修正：探测用错大小写会把本来可用的模型记成不可用，进而从 `/v1/models` 消失。

### 变更

- 删除从未被调用的按能力挑号逻辑（`pickAccount`、`pickByCatalog`、`discoverMissingCatalogs`、`accountCanServe`）及只覆盖它们的测试。

### 使用与升级

从本次 Release 下载对应平台压缩包，解压后运行 `codearts2api-panel.exe`（Windows）或 `./codearts2api-panel`（Linux）。首次运行会创建包含独立随机密钥的 `config.json`，在 `http://127.0.0.1:7866/panel` 使用 `admin_key` 登录。

升级前停止旧进程并备份 `config.json`、`auths/` 和 `data/`，然后仅替换程序文件；不要用示例配置覆盖已有配置。安装包不含真实配置或账号凭据。
