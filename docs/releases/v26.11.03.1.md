用量页改由服务端按时间范围聚合，汇总可按模型或按账号查看；网关补上输入/输出模态声明，请求归档保留期改为可配置。

### 新增

- `/v1/models` 的每个模型条目新增 `input_modalities` / `output_modalities`：支持图片的模型声明 `["text","image"]`，其余为 `["text"]`，客户端不必再靠猜或缺字段来判断能不能贴图。
- 请求归档保留期改为配置项 `request_log_retention_days`（默认 30 天，此前写死 7 天）。面板「日志与归档」可直接改，保存后一秒内生效；0/负数视为未配置，回落默认而不是删光。
- 模型目录页给不支持视觉输入的模型补中性灰「纯文本」徽标，与绿色「视觉理解」互斥 —— 原来没有徽标既可能是纯文本、也可能是上游没表态，看不出来。
- 用量页顶部新增平均首字时间（TTFT）、平均缓存命中率、输入 / 输出 / 总计 Token。TTFT 只平均真正返回过首字的请求；命中率按已上报缓存的 token 加权，卡片下方同时给出命中与未命中的 token 数；没有样本时显示 `—` 而不是 0。
- 用量页新增时间范围：今天 / 近 24 小时 / 近 3 天 / 近 7 天 / 近 30 天 / 自定义。窗口由服务端扫归档聚合（`/admin/api/usage?window=1`），卡片、趋势图与汇总表都是整段窗口的全量统计，不再受「最近 300 条样本」限制；汇总表可在按模型 / 按账号之间切换，按模型额外给出平均 TTFT 与输出 TPS（输出 token ÷ (耗时 − 首字时间)，按样本加权）。
- 运行日志页新增「尝试次数」列：重试过的请求把最后一次上游错误挂在该单元格的原生 tooltip 上，一次成功的请求不显示 tooltip。

### 修复

- `/v1/models` 不再为同一个模型列出注册名与小写别名两条：统一按小写 ID 去重，发往上游时再还原成该账号登记的写法。
- 上游错误文本的截断从 160 / 200 字节统一到 300 字节，且不再从多字节字符中间切断（半个字符会以 U+FFFD 到达客户端，且上游错误码后的解释被吃掉）。
- Docker 镜像的监听端口绑定到所有网卡，不再是 localhost，否则容器内 `127.0.0.1:7866` 从宿主机访问不到。

### 变更

- 面板前端删掉了自己那套用量口径（逐条合并、TTFT / 缓存 / Token 计算），改由服务端一次算完并只回聚合结果与按模型 / 按小时汇总；运行日志页仍走逐条记录，不受用量页时间范围影响。

### 使用与升级

从本次 Release 下载对应平台压缩包，解压后运行 `codearts2api-panel.exe`（Windows）或 `./codearts2api-panel`（Linux）。首次运行会创建包含独立随机密钥的 `config.json`，在 `http://127.0.0.1:7866/panel` 使用 `admin_key` 登录。

升级前停止旧进程并备份 `config.json`、`auths/` 和 `data/`，然后仅替换程序文件；不要用示例配置覆盖已有配置。本次新增的 `request_log_retention_days` 不写也按 30 天执行，旧配置无需修改。安装包不含真实配置或账号凭据。
