本次为 fork 版本，包含上游 `v26.11.05.1` 之后的全部改动：新增 Anthropic Messages 协议端点（Claude Code 可直连）、原生 Android 版（网关跑在 App 进程内）、账号池只读共享模式，以及多项错误分类、余额趋势与面板修复。

### 新增

- 新增 `/v1/messages`（Anthropic Messages）端点，支持流式与非流式、工具调用，Claude Code 可直连；同时补齐 OpenAI Responses 与 Chat Completions、Anthropic 三者之间的请求/响应互转。
- 新增原生 Android 版：把同一套 Go 网关以 c-shared 库 + JNI 跑在 App 进程内（`mobile/jni.go`、`android/`），手机自身即 API 服务器，默认端口 17866，WebView 复用 `/panel`。App 自己 exec 的子进程会被 Android 冻结，进程内运行才受前台服务保护。
- 新增账号池只读模式，允许两个网关共享同一批账号而不互相改写凭据。
- 姓名模型可用性改为从真实流量学习，不再额外发送探测请求；默认隐藏已确认不可用的模型。
- 余额趋势支持多账号折线与每日变化，改为每 30 分钟采样、成功采样按 5 分钟去重；账号页支持备注字段。
- 新增账号选择策略 `account_strategy`（`first` / `credits` / `round_robin`）。

### 修复与调整

- 统一三条聊天路径的错误分类器；上游 5xx 计入错误阈值；参数错误、非多模态输入、上下文超长与客户端取消不再误伤健康账号，也不再释放请求已不再持有的槽位。
- 手动 keepalive 现在能真正唤醒因凭据过期而冷却的账号。
- 面板导航兼容 Chrome 81 等旧 WebView（`Object.hasOwn`、CSS `inset`、`100dvh`、`color-mix` 等均已加回退）。
- Anthropic 端点尊重客户端指定的模型，且不再注入 `reasoning_effort`。
- 上游聊天身份请求头对齐官方 CLI，并改用官方 Bun User-Agent。
- 修复 Windows 路径与 CRLF 导致配置重载被跳过的问题。

### Android

Release 附件中的 APK 与本次网关同源（`android/version.txt` 记为 `v26.11.10-android.1`）。安装后首次启动需按机型授予「允许后台运行」（ColorOS 等 ROM 会冻结整个 UID，电池白名单与前台服务通知都挡不住），详见 `android/README.md`。

### 使用与升级

从本次 Release 下载对应平台压缩包，解压后运行 `codearts2api-panel.exe`（Windows）或 `./codearts2api-panel`（Linux）。首次运行会创建包含独立随机密钥的 `config.json`，在 `http://127.0.0.1:7866/panel` 使用 `admin_key` 登录。

升级前停止旧进程并备份 `config.json`、`auths/` 和 `data/`，然后仅替换程序文件；不要用示例配置覆盖已有配置。安装包不含真实配置或账号凭据。

注意：电脑与手机同时运行同一批账号会互相作废 `refresh_token`，请避免双端并发使用同一账号。
